# AstrBot Ambient Reply

一个专注于双模式群聊接话的 AstrBot 插件。机器人先以较低概率参与普通群聊；成功接话后短时进入高概率状态，让对话更连贯，同时避免长期刷屏。

## 功能

- 普通模式默认 `33%` 接话概率。
- 自动接话后默认进入 `90 秒` 高频模式，接话概率提升至 `80%`。
- 每次在高频模式中成功接话，都会重新计算 90 秒。
- 高频模式只限制概率，不受普通冷却和次数上限影响。
- 普通模式保留同群冷却、同用户冷却和 10 分钟次数上限。
- 能识别被 @ 的其他成员，不会把自己的话误当成对机器人的指令。
- 忽略 `@全体成员` 和以 `/`、`!`、`#sl` 开头的命令。
- 支持机器人发送者黑名单，避免两个接话机器人互相追答。
- 支持按 QQ 群启用。

## 安装

1. 下载对应版本的 ZIP。
2. 在 AstrBot 插件管理中上传 ZIP。
3. 确认插件 `ambient_reply` 已启用。
4. 在插件配置中按需填写生效群号和机器人发送者 QQ 号。

也可以直接将本目录作为独立的 AstrBot 插件安装。

## 与文字唤醒插件的区别

本插件只决定机器人是否“自然插话”，不会因为消息中出现特定关键词而强制回复。

如需“消息任意位置出现‘虎’就唤醒机器人”，请同时安装独立的
`astrbot_plugin_keyword_wake`。两个插件同时启用时，文字唤醒会先认领消息，
本插件不会重复接管。

## 高频模式说明

第一次开口仍要经过普通模式概率和冷却判断。成功开口后才会进入高频状态。
因此普通冷却控制的是“每次从安静状态重新加入聊天的资格”，不会影响已经进入
高频状态后的连续回复。

## 配置

配置会保存在 AstrBot 的 `data/config/astrbot_plugin_ambient_reply_config.json`。

| 配置项 | 默认值 | 说明 |
| --- | ---: | --- |
| `enabled` | `true` | 是否启用 |
| `enabled_group_ids` | `[]` | 生效群号，空表示全部群聊 |
| `reply_probability` | `0.33` | 普通模式概率 |
| `high_frequency_probability` | `0.8` | 高频模式概率 |
| `high_frequency_duration_seconds` | `90` | 高频状态时长 |
| `min_group_interval_seconds` | `75` | 普通模式同群冷却 |
| `min_user_interval_seconds` | `180` | 普通模式同用户冷却 |
| `max_replies_per_10_minutes` | `3` | 普通模式次数上限 |
| `min_text_chars` | `2` | 最短触发文本 |
| `ignored_sender_ids` | `[]` | 忽略的机器人发送者 |

## 兼容性

- 面向 AstrBot `4.x` 开发。
- 已在 AstrBot `4.29.3` 下验证核心行为。
- LLM 请求钩子兼容第三方包装器传入额外位置参数的情况。

## 注意

高概率模式可能让机器人在活跃群聊中连续回复。建议先在小群测试概率、冷却和
机器人发送者黑名单，再决定是否对所有群开放。
